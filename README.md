## 🚀 Installation Guide

### 🪟 Windows (Installer)
1. Download **`ArcRaidersCompanion-Windows.exe`**.
2. Run the executable installer.
3. Follow the on-screen setup wizard to install ARC Raiders Companion directly into your Programs folder with start menu and desktop shortcuts.

### 🤖 Android (APK)
1. Download **`ArcRaidersCompanion-Android.apk`**.
2. Open the downloaded file on your device.
3. Allow *Install from unknown sources* in your security settings if prompted, then tap **Install**.

### 📱 iOS (Sideloading)
1. Download **`ArcRaidersCompanion-iOS-unsigned.ipa`**.
2. Sideload using your preferred sideloading manager (**AltStore**, **SideStore**, **TrollStore**, **Scarlet**, or Xcode).
3. Trust your profile under **Settings &rarr; General &rarr; VPN & Device Management**.

### 🍏 macOS (Universal)
1. Download **`ArcRaidersCompanion-macOS.zip`**.
2. Extract the archive and drag **ARC Raiders Companion.app** to your `/Applications` directory.
3. If macOS Gatekeeper alerts that the app is unverified, run:
   ```bash
   xattr -cr /Applications/ArcRaidersCompanion.app
   ```
   Or right-click the application in Finder and select **Open**.

### 🐧 Linux (x64)
1. Download **`ArcRaidersCompanion-Linux-x64.tar.gz`**.
2. Extract and launch:
   ```bash
   tar -xzf ArcRaidersCompanion-Linux-x64.tar.gz
   cd ArcRaidersCompanion-Linux-x64
   ./arc_raiders_companion
   ```
